# Calibration run 3: Jev, 2026-09-18

Third live run of `bouncer calibrate` against `jev-1.13.0` over the 81 fixtures.
Confidence is `max(p, 1 − p)`.

**Nothing changed since [run 2](2026-09-18-jev-2.md):** same fixtures, same policy, same
model version. This run exists to measure run-to-run variation on its own, which run 1
versus run 2 could not, because the `prod` criteria changed between them.

**What it shows.** Every overall accuracy is identical to run 2 and no Brier score moved by
more than 0.01. The buckets below 0.9 did not hold still: `destructive` at 0.8–0.9 went
from 0% of 3 to 20% of 5, `secrets` at 0.8–0.9 from 67% of 3 to 100% of 3, and
`sensitive_target` at 0.6–0.7 from 0% of 1 to 50% of 2. No verdict changed. Fixtures whose
`p` sits near a bucket edge drift across it from run to run and take their correctness with
them, and with one to five fixtures per bucket that is enough to move a cell by a whole
step. The row is stable; the buckets are not.
